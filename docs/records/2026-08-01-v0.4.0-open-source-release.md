## 停止条件

- 任一四项矩阵失败；
- Tag 或 Release 已存在且目标不一致；
- Release 资产的重新计算摘要不等于记录摘要；
- GitHub 设置 API 权限不足；
- diff 出现未经设计批准的 Core、Adapter、Schema 或 Skill 行为修改。

停止时保留已经通过的本地提交和远端 PR，不伪造 PASS、不覆盖 Tag，也不通过强推绕过保护。
