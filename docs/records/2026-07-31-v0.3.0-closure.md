## 已可用产品能力

- From-scratch：自然语言 goal 经逐问访谈、唯一 Loopability Gate、Candidate Review 和批准边界，
  产出 0-loop Workflow 或 1-loop bounded Loop Skill；
- Existing Skill：完整只读 Assessment、Decision Record、共享 Gate/Review、source inventory 与
  Manifest-bound 保源构建；支持 regular `package.json`、missing frontmatter 和非权威目录名；
- Conversation：授权记录经 Observed Workflow Model、渐进澄清和共享 Gate/Review，产出 0-loop
  Workflow 或兼容 1-loop Skill；
- Direct Build：已批准 JSON/散文 Definition 经机械校验/转写，以
  `entry-evidence-v0.2` 和 `candidate_review: null` 如实构建；
- Verify：对完整 build root 只读返回 clean 或 drifted，不修复、不重建；
- Multi-Loop：两个及以上独立 Loop 明确返回 Assessment/unsupported，不压缩成当前输出。
