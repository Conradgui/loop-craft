# Loop Craft 0.3.0 Strict Closure Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在不扩大 0.3.0 产品边界的前提下，修复 Direct Build provenance 与 Existing Skill 常见包形可达性，完成安装一致性、未知 Agent 产品流程审计、许可证和 GitHub 阶段出口。

**Architecture:** 三种设计入口继续汇合到 Shared Gate → Candidate Review → Definition → Core；Direct Build 以独立的 v0.2 Entry Evidence 表达“未发生 Candidate Review”。Existing Skill 只做最小安全扩展：允许 package.json、允许缺失 frontmatter 的正文由已批准 Definition 补 canonical frontmatter，但身份冲突与链接越界继续 fail closed。

**Tech Stack:** Markdown Agent Skill、Python 3.11+、JSON Schema Draft 2020-12、pytest、Git/GitHub Actions、Codex CLI。
